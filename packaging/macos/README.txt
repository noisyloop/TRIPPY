TRIPPY for macOS
================

1. Drag TRIPPY into Applications.

2. First launch: this build is not signed by Apple, so macOS will block a
   double-click. Either right-click TRIPPY > Open > Open, or run once in Terminal:

     xattr -dr com.apple.quarantine /Applications/TRIPPY.app

3. Arrows/WASD move, E/Space talk, I inventory, Esc quits (autosaves).

Save file: ~/Library/Application Support/trippy/save.json (delete to start over)
