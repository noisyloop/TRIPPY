TRIPPY for Windows
==================

1. Unzip the whole folder anywhere (keep trippy.exe next to the assets folder).

2. Double-click trippy.exe. This build is not signed, so Windows SmartScreen may
   say "Windows protected your PC": click More info > Run anyway.

3. Arrows/WASD move, E/Space talk, I inventory, Esc quits (autosaves).

Save file: %APPDATA%\trippy\save.json (delete to start over)
